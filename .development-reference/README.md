# .development-reference

这个目录不属于任何 skill。

它只负责保存 skill 开发过程里的参考资料，例如：

- 重构参考文
- 流程拆分文
- 设计说明文
- 流程图草稿
- 还没同步回正式 skill 的中间稿

这里的内容默认不是最终对外文档，也不是最终执行入口。

推荐工作方式：

1. 先在这里整理和收敛某个 skill 的参考文
2. 等参考文稳定后，再同步回对应的 `SKILL.md`
3. 如有必要，再同步到根目录 `README.md` 或其他正式说明文件

目录约定：

- 一个 skill 对应一个子目录
- 相关参考文、流程稿、图稿尽量放在同一个子目录里

当前目录示例：

- `yeizi-command-bug-workflow/`
