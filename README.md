# yeizi-skills

`yeizi-skills` 是一个 skills 包，收录了我整理的一些常用 skills。

用户可以直接下载这个仓库，把需要的 skill 文件夹复制到自己的 `skills` 目录中使用。

## 使用方式

1. 下载或克隆本仓库
2. 选择需要的 skill 文件夹
3. 复制到自己的 `skills` 目录
4. 在 AI 工具中调用对应 skill

## Quick Start

目录示例：

```text
your-skills/
└── refine-and-self-review/
    └── SKILL.md
```

调用示例：

`使用 refine-and-self-review 继续完善当前模块`

## 当前 Skills

### `refine-and-self-review`

作用：

- 处理“优化、补充、修复、继续完善”这类请求

功能：

- 先完成当前任务
- 再检查结果是否还有明显缺口
- 需要时补充下一步建议

适用场景：

- 代码优化
- Bug 修复
- 文档补充
- 方案完善
- 功能继续实现
